# cafe-landing

가상의 동네 카페 "온기 카페"를 소개하는 간단한 정적 랜딩 페이지입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (메뉴, 소개, 오시는 길 섹션) |
| `style.css` | 스타일 (반응형 레이아웃, 카페 톤의 색상) |

## 미리보기

별도 빌드 없이 `index.html`을 브라우저로 열면 됩니다.

## 수정 방법

- 카페 이름, 주소, 전화번호, 메뉴와 가격은 `index.html`에서 바꿉니다. 현재 값은 예시입니다.
- 색상과 레이아웃은 `style.css`에서 바꿉니다.
